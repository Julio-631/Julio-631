## Sobre

Trabalho na interseção entre **nuvem, dados e automação corporativa** — desenhando
integrações e governança sobre Microsoft 365, Power Platform e AWS.

- Governança de identidades e federação (**Entra ID**, SAML, SCIM)
- Plataformas de dados e BI (**Amazon Quick / QuickSight**, SAP HANA)
- Agentes e automação (**Copilot Studio**, **Microsoft Graph**, MCP)
- Automação de infraestrutura com **PowerShell** e **Python**
